GRAPHER
=======
Unzip the folder and double-click index.html to open it in any modern browser.
No internet connection, installation, or server required. Uses no external libraries or AI services.

index.html        page structure
css/styles.css    colors, light/dark mode, and responsive layout
js/formulas.js    expression parser (no eval)
js/graph.js       canvas rendering
js/app.js         interface, sliders, saving

Colors can be customized in the first lines of styles.css and in PALETTE (app.js).
Syntax help is available via the "?" button in the app.
