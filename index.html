    How to write formulas

    Functiony = x^2 - 3 or just x^2 - 3
    x as a function of yx = sin(y)
    Implicit equationx^2 + y^2 = 25
    Inequalityy < 2x + 1, x^2 + y^2 <= 4
    Polarr = 2 + cos(5θ) (you can type theta)
    Parametric(4cos(3t), 4sin(2t))
    Point(2, f(2))
    Define and reusef(x) = x^3 - x, then f(x - 2)
    Derivativesf'(x), f''(x) or the “Derivative” button
    Parametersa sin(b x) creates sliders for a and b
    Restrict domainy = x^2 {-1 < x < 2}
    CommentLines starting with # are not plotted

    Functions: sin, cos, tan, sec, csc, cot, asin, acos, atan, atan2, sinh, cosh, tanh, sqrt (√), cbrt, root(n, x), abs or |x|, exp, ln, log (base 10), log2, log(base, x), floor, ceil, round, sign, min, max, mod, gamma, factorial (n!).

    Constants: pi (π), e, tau (τ). Angles are in radians and decimals use a dot.

    Mouse & keyboard: drag to pan and use the scroll wheel to zoom. Shift + wheel scales only the x-axis; Alt + wheel scales only the y-axis. On touch screens, pinch to zoom. Enter adds a new formula.
